🪟 Windows Setup Guide

Install Minima on your Windows PC

← All Guides macOS Linux

Overview

Minima on Windows uses OpenWebStart to run. OpenWebStart is a free tool that lets your PC run Java applications like Minima. This guide will walk you through installing everything you need.

What You'll Need

  • Windows 10 or Windows 11
  • About 500MB of free disk space
  • Internet connection for download and initial sync
  • Node.js and Git (for miniMerch CLI)

Install Node.js

miniMerch uses a command-line tool that requires Node.js.

  1. Go to nodejs.org
  2. Download the Windows Installer (.msi) - choose the LTS version
  3. Open the downloaded file
  4. Follow the install wizard - click Next, accept the license, click Install
  5. Finish the installation

To verify Node.js is installed, open Command Prompt and run:

node --version

Install Git

Git is a version control system needed to download the miniMerch source code.

  1. Go to git-scm.com/download/win
  2. The download should start automatically
  3. Open the downloaded file
  4. Follow the install wizard - accept defaults are fine
  5. Finish the installation

To verify Git is installed, open Command Prompt and run:

git --version

Install miniMerch CLI

You have two options for installing the miniMerch command-line tool:

Option A: Global Install (Quick Setup)

Install globally with npm - use this if you just want to run miniMerch commands:

  1. Open Command Prompt (search for "cmd" in Start menu)
  2. Run:
npm install -g @eurobuddha/mini-merch

After this, you can run miniMerch commands directly.

Option B: Local Install (Full Source)

Clone the repository to your computer - use this if you want the full source code:

  1. Open Command Prompt
  2. Navigate to where you want to keep your files (e.g., Documents):
cd %USERPROFILE%\Documents
  1. Clone the miniMerch repository:
git clone https://github.com/eurobuddha/miniMerch.git
  1. Go into the folder:
cd miniMerch
  1. Install dependencies:
npm install

After this, run miniMerch commands with node ./src/index.js followed by the command.

Step 1: Download OpenWebStart

OpenWebStart is a free application that allows your PC to run Java programs like Minima.

  1. Open your web browser and go to openwebstart.com
  2. Click the big Download button
  3. Save the file to your Downloads folder

Step 2: Install OpenWebStart

  1. Open your Downloads folder
  2. Find the file starting with OWS-Setup
  3. Double-click it to run the installer
  4. If Windows shows a warning, click Run anyway
  5. The installer will open - click Next
  6. Accept the license agreement and click Next
  7. Click Install
  8. Wait for installation to complete, then click Finish
💡 SmartScreen Warning

Windows SmartScreen may show a warning about OpenWebStart. This happens because OpenWebStart is not a well-known app. Click More info then Run anyway. OpenWebStart is safe and legitimate.

Step 3: Download Minima JNLP from SpartacusRex.com

The Minima application is downloaded as a JNLP file from SpartacusRex.com. This file tells OpenWebStart what to download.

📥 minima.jnlp

Right-click and "Save Link As..." to save the file

  1. Right-click the button above
  2. Select "Save Link As..." or "Download Linked File As..."
  3. Save the file as minima.jnlp to your Downloads folder

Step 4: Launch Minima

Now let's start Minima for the first time:

  1. Open your Downloads folder
  2. Find the minima.jnlp file
  3. Right-click it and select Open with
  4. Choose OpenWebStart
  5. If OpenWebStart isn't in the list, click Choose another app and browse for OpenWebStart (usually in C:\Program Files\OpenWebStart)
  6. OpenWebStart will download and install Minima
  7. This may take a few minutes - be patient!

Step 5: Your Wallet

The Minima node IS your wallet. There's a built-in Wallet MiniDapp for managing your tokens.

  1. Look for the Wallet MiniDapp in your MiniDapp Hub
  2. Open it to see your addresses and balance
  3. Your 24-word recovery phrase is stored securely - back it up if you haven't already

Step 6: Connect to Network

On first run, Minima connects to the network - this takes about 10 seconds.

  1. When prompted, click to connect to the network
  2. Wait a few seconds for the connection
  3. You're ready to go!

Step 7: Create a Shortcut

Let's create a shortcut so you can easily start Minima in the future:

  1. Right-click the minima.jnlp file in your Downloads
  2. Select Create shortcut
  3. Move the shortcut to your Desktop for easy access

Now to start Minima, just double-click the shortcut on your Desktop!

Step 8: Get Your Keys

You'll need your keys for miniMerch setup. Open the Terminal MiniDapp in Minima:

Minima Address

Your address for receiving payments (starts with 0x):

  1. Open the Wallet MiniDapp
  2. Click Receive
  3. Copy your address

Maxima mxpublickey

Your public key for encrypting orders (starts with Mx):

  1. Open the Terminal MiniDapp
  2. Type maxima and press Enter
  3. Find the line with "mxpublickey":
  4. Copy the value

Updating Minima

When a new version of Minima is released:

  1. Close Minima completely
  2. Double-click minima.jnlp again (or your shortcut)
  3. OpenWebStart will download and install the new version
  4. Your wallet and history are preserved

Troubleshooting

OpenWebStart doesn't open JNLP files

  • Right-click minima.jnlp → Open with → Choose OpenWebStart
  • Make sure "Always use this app" is checked
  • If OpenWebStart isn't listed, browse to C:\Program Files\OpenWebStart\

SmartScreen blocks the installer

  • Click More info
  • Click Run anyway
  • OpenWebStart is safe - it's an open source project

Sync is stuck

  • Check your internet connection
  • Close Minima and restart it
  • Make sure Windows isn't in sleep mode during sync
  • Check that Windows Firewall isn't blocking Minima

Minima won't start

  • Make sure OpenWebStart is properly installed
  • Try right-clicking minima.jnlp and choosing "Run as administrator"
