🪟 Windows Setup Guide

Install Minima Desktop on your Windows PC

← All Guides macOS Linux

Prerequisites

  • Windows 10 or Windows 11
  • At least 500MB of free disk space
  • Stable internet connection
  • Administrator privileges (for installation)
  • Optional: Java 17+ if running the JAR version

Step 1: Download Minima

Download the Windows installer from the official Minima website:

  1. Visit minima.global/post/2024/04/10/minima-desktop-launch/
  2. Click the Windows download link
  3. Choose either:
    • MSI Installer - For a standard Windows installation
    • JAR File - For users who prefer Java
  4. The file will download to your Downloads folder

Checking Java Version (for JAR)

If using the JAR version, check your Java installation:

  1. Open Command Prompt (Win + R, type cmd, press Enter)
  2. Type: java -version
  3. If you see "java version 17" or higher, you're good
  4. If not, download Java from java.com

Step 2: Install Minima

MSI Installer (Recommended)

  1. Open the downloaded MSI file
  2. If prompted, click Yes to allow changes
  3. The Setup Wizard will appear
  4. Click Next
  5. Choose installation location (default is fine)
  6. Click Install
  7. Wait for installation to complete
  8. Click Finish
  9. Minima should launch automatically

JAR Version

  1. Create a folder for Minima (e.g., C:\Minima)
  2. Move the JAR file to that folder
  3. Open Command Prompt
  4. Navigate to the folder: cd C:\Minima
  5. Run: java -jar minima.jar
💡 Creating a Shortcut

For the JAR version, create a shortcut on your desktop: Right-click → New → Shortcut → enter the command above.

Step 3: Create Your Wallet

When you first open Minima, you'll see the setup wizard.

Option A: Create New Wallet

  1. Click "Create New Wallet"
  2. Minima will generate a secure 24-word recovery phrase
  3. IMPORTANT: Write down your recovery phrase on paper
  4. Click "I've Written It Down"
  5. Confirm your recovery phrase by entering 3 random words
  6. Create a password for encrypting your wallet
  7. Your wallet is ready!

Option B: Restore Existing Wallet

  1. Click "I Have a Seed"
  2. Enter your 24-word recovery phrase
  3. Confirm each word carefully
  4. Create a new password
  5. Your existing wallet and balance will be restored
⚠️ Security Warning

Never share your recovery phrase with anyone. Store it somewhere safe - this is your only key to your funds.

Step 4: Sync with the Network

After creating your wallet, Minima will begin syncing with the blockchain.

  1. Keep Minima open while syncing
  2. The status bar shows sync progress
  3. Initial sync may take 15-30 minutes
  4. Once synced, you can minimize or close the app
💡 Auto-start Option

To run Minima automatically when Windows starts: Settings → Startup → Enable "Launch at startup"

Step 5: Find Your Public Key

You'll need your public key for miniMerch setup:

  1. In Minima Desktop, click Maxima in the sidebar
  2. Your public key is displayed at the top
  3. Click the key to copy it to your clipboard
  4. Your public key starts with Mx

Alternatively, open the Minima Terminal and type:

maxima

Troubleshooting

Windows Defender or SmartScreen blocks installation

  • Click More Info → Run Anyway
  • Minima is a legitimate application - the warning is a false positive

Java error when running JAR

  • Make sure Java 17+ is installed
  • Download from adoptium.net (free, open-source Java)
  • Restart your computer after installing Java

Sync is very slow

  • Check your internet connection
  • Try disabling other bandwidth-heavy applications
  • Restart Minima
  • Check Windows Firewall isn't blocking Minima
