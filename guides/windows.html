🪟 Windows Setup Guide

Install Minima on your Windows PC using OpenWebStart

← All Guides macOS Linux

Prerequisites

  • Windows 10 or Windows 11
  • At least 500MB of free disk space
  • Stable internet connection

Step 1: Install OpenWebStart

OpenWebStart is a free tool that allows you to run Java applications like Minima.

  1. Download OpenWebStart from openwebstart.com
  2. Click the Download button
  3. Run the downloaded installer (OWS-Setup-*.exe)
  4. Follow the installation wizard
  5. Click Install
  6. Wait for installation to complete
💡 Note

If Windows shows a SmartScreen warning, click More info → Run anyway. OpenWebStart is a legitimate application.

Step 2: Download Minima

Download the Minima launcher file:

  1. Visit spartacusrex.com/jnlp.html
  2. Click the Download Minima JNLP link
  3. The file will download to your Downloads folder

Step 3: Launch Minima

Double-click the downloaded JNLP file to start Minima:

  1. Navigate to your Downloads folder
  2. Double-click minima.jnlp
  3. If prompted, choose OpenWebStart to open the file
  4. OpenWebStart will download the Minima application
  5. The first launch may take a few minutes
📍 Creating a Desktop Shortcut

To create a shortcut:

  1. Right-click minima.jnlp
  2. Click Create shortcut
  3. Move the shortcut to your Desktop

Step 4: Create Your Wallet

When you first open Minima Desktop, you'll see the setup wizard.

Option A: Create New Wallet

  1. Click "Create New Wallet"
  2. Minima will generate a secure 24-word recovery phrase
  3. IMPORTANT: Write down your recovery phrase on paper
  4. Click "I've Written It Down"
  5. Confirm your recovery phrase by entering 3 random words
  6. Create a password for encrypting your wallet
  7. Your wallet is ready!

Option B: Restore Existing Wallet

  1. Click "I Have a Seed"
  2. Enter your 24-word recovery phrase
  3. Confirm each word carefully
  4. Create a new password
  5. Your existing wallet and balance will be restored
⚠️ Security Warning

Never share your recovery phrase with anyone. Store it somewhere safe - this is your only key to your funds.

Step 5: Sync with the Network

After creating your wallet, Minima will begin syncing with the blockchain.

  1. Keep Minima open while syncing
  2. The status bar shows sync progress
  3. Initial sync may take 15-30 minutes
  4. Once synced, you can close the app

Step 6: Find Your Public Key

You'll need your public key for miniMerch setup:

  1. In Minima Desktop, click Maxima in the sidebar
  2. Your public key is displayed at the top
  3. Click the key to copy it to your clipboard
  4. Your public key starts with Mx

Updating Minima

One of the benefits of OpenWebStart is automatic updates:

  1. Close Minima
  2. Double-click minima.jnlp again
  3. OpenWebStart will check for and install any updates
  4. Your wallet and settings are preserved

Troubleshooting

OpenWebStart won't open JNLP files

  • Right-click the JNLP file → Open with → Choose another app
  • Select OpenWebStart from the list
  • Check "Always use this app"

SmartScreen blocks installation

  • Click More info
  • Click Run anyway
  • OpenWebStart is a legitimate, open-source application

Sync is very slow

  • Check your internet connection
  • Try restarting Minima
  • Make sure Windows Firewall isn't blocking Minima

Need more help?
