🍎 macOS Setup Guide

Install Minima Desktop on your Mac

← All Guides Windows Linux

Prerequisites

  • Mac computer running macOS 11 (Big Sur) or later
  • At least 500MB of free disk space
  • Stable internet connection
  • Optional: Java 17+ if running the JAR version

Step 1: Download Minima

Download the macOS installer from the official Minima website:

  1. Visit minima.global/post/2024/04/10/minima-desktop-launch/
  2. Click the macOS download link
  3. The DMG file will download to your Downloads folder

Alternative: JAR Version

If you prefer the command-line version:

  1. Download the JAR file from the same page
  2. Make sure you have Java 17 or later installed
  3. Run with: java -jar minima.jar

Step 2: Install Minima

DMG Version (Recommended)

  1. Open the downloaded DMG file
  2. Drag the Minima app to the Applications folder
  3. Wait for the copy to complete
  4. Eject the DMG drive
  5. Open Minima from Applications or Spotlight
⚠️ Gatekeeper Warning

On first launch, macOS may show "Minima can't be opened because it wasn't downloaded from the App Store." Click System Settings → Security → Open Anyway to allow it.

Step 3: Create Your Wallet

When you first open Minima Desktop, you'll see the setup wizard.

Option A: Create New Wallet

  1. Click "Create New Wallet"
  2. Minima will generate a secure 24-word recovery phrase
  3. IMPORTANT: Write down your recovery phrase on paper
  4. Click "I've Written It Down"
  5. Confirm your recovery phrase by entering 3 random words
  6. Create a password for encrypting your wallet
  7. Your wallet is ready!

Option B: Restore Existing Wallet

  1. Click "I Have a Seed"
  2. Enter your 24-word recovery phrase
  3. Confirm each word carefully
  4. Create a new password
  5. Your existing wallet and balance will be restored

Step 4: Sync with the Network

After creating your wallet, Minima will begin syncing with the blockchain.

  1. Keep Minima open while syncing
  2. The status bar shows sync progress
  3. Initial sync may take 15-30 minutes
  4. Once synced, you can minimize the app - it runs in the background
💡 Running in Background

Minima Desktop runs efficiently in the background. You can quit the app when not in use - your node will stop, but no funds are at risk.

Step 5: Find Your Public Key

You'll need your public key for miniMerch setup:

  1. In Minima Desktop, click Maxima in the sidebar
  2. Your public key is displayed at the top
  3. Click the key to copy it to your clipboard
  4. Your public key starts with Mx

Alternatively, use the Terminal command:

maxima

This displays your full contact address including public key.

Troubleshooting

App won't open - Gatekeeper blocked

  • Go to System Settings → Privacy & Security
  • Find the message about Minima
  • Click Open Anyway

Sync is very slow

  • Check your internet connection
  • Try connecting to different peers
  • Restart Minima
  • Make sure your Mac isn't in sleep mode during sync

Forgot password

Use your 24-word recovery phrase to restore your wallet in a new installation.
