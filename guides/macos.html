🍎 macOS Setup Guide

Install Minima on your Mac computer

← All Guides Windows Linux

Overview

Minima on macOS uses OpenWebStart to run. OpenWebStart is a free tool that lets your Mac run Java applications like Minima. This guide will walk you through installing everything you need.

What You'll Need

  • Mac computer running macOS 10.15 (Catalina) or later
  • About 500MB of free disk space
  • Internet connection for download and initial sync

Step 1: Download OpenWebStart

OpenWebStart is a free application that allows your Mac to run Java programs like Minima.

  1. Open your web browser and go to openwebstart.com
  2. Click the big Download button
  3. Save the file to your Downloads folder

Step 2: Install OpenWebStart

  1. Open your Downloads folder
  2. Double-click the OpenWebStart DMG file you downloaded
  3. A window will open showing the OpenWebStart icon
  4. Drag the OpenWebStart icon to your Applications folder
  5. Wait for it to finish copying, then eject the DMG
💡 Allowing OpenWebStart to Run

The first time you open OpenWebStart, macOS may block it. You'll see a message saying OpenWebStart can't be opened. To fix this:

  1. Go to System Settings → Privacy & Security
  2. Scroll down until you see a message about OpenWebStart being blocked
  3. Click Open Anyway

Step 3: Download Minima JNLP from SpartacusRex.com

The Minima application is downloaded as a JNLP file from SpartacusRex.com. This file tells OpenWebStart what to download.

📥 minima.jnlp

Right-click and "Save Link As..." to save the file

  1. Right-click the button above
  2. Select "Save Link As..." or "Download Linked File As..."
  3. Save the file as minima.jnlp to your Downloads folder

Step 4: Launch Minima

Now let's start Minima for the first time:

  1. Open your Downloads folder
  2. Find the minima.jnlp file
  3. Double-click it
  4. If asked to choose an app, select OpenWebStart
  5. OpenWebStart will download and install Minima
  6. This may take a few minutes - be patient!
⏱️ First Launch Takes Time

The first time you run Minima, it needs to download the full application (around 100MB) and then sync with the blockchain. This can take 10-20 minutes.

Step 5: Create Your Wallet

When Minima first opens, you'll set up your wallet. This is where your Minima tokens will be stored.

Creating a New Wallet

  1. Click "Create New Wallet"
  2. Minima will generate a secret 24-word recovery phrase
  3. IMPORTANT: Write down all 24 words on paper in order
  4. Store this paper somewhere safe - this is your only backup!
  5. Click "I've Written It Down"
  6. Enter 3 of the words to confirm you've saved them correctly
  7. Create a password for your wallet
  8. Click Create Wallet
⚠️ Save Your Recovery Words!

Your 24-word recovery phrase is the ONLY way to restore your wallet if your computer breaks or you forget your password. Write it down and keep it safe. Never share it with anyone.

Restoring an Existing Wallet

If you already have a Minima wallet:

  1. Click "I Have a Seed"
  2. Enter your 24-word recovery phrase
  3. Click Restore
  4. Create a new password

Step 6: Wait for Sync

After creating your wallet, Minima needs to sync with the blockchain. This downloads all the transaction history.

  1. Keep Minima open
  2. Watch the progress bar at the bottom
  3. Wait until it shows 100% synced
  4. This can take 15-30 minutes on first run
💡 You Can Minimize Minima

While syncing, you can minimize the window and continue using your Mac. Just don't close the app. OpenWebStart keeps Minima running in the background.

Step 7: Keep Minima Running

For miniMerch to receive orders, Minima needs to be running. Let's set up a way to start it easily:

  1. Right-click the Minima icon in your Dock
  2. Select Options
  3. Click Keep in Dock

Now Minima will appear in your Dock. To start it in the future:

  1. Click the Minima icon in your Dock
  2. If you see "Downloading Minima", just wait
  3. Your wallet and sync will load

Finding Your Public Key

You'll need your public key to set up miniMerch. Here's how to find it:

  1. In Minima, click Maxima in the left sidebar
  2. Your public key is shown at the top
  3. Click the key to copy it
  4. Your public key starts with Mx

Save this somewhere - you'll need it for miniMerch setup.

Updating Minima

When a new version of Minima is released:

  1. Close Minima completely
  2. Double-click minima.jnlp again
  3. OpenWebStart will download and install the new version
  4. Your wallet and history are preserved

Troubleshooting

OpenWebStart doesn't open JNLP files

  • Right-click minima.jnlp → Open With → OpenWebStart
  • Or drag minima.jnlp onto the OpenWebStart icon in Applications

macOS won't let me open OpenWebStart

  • Go to System Settings → Privacy & Security
  • Look for the blocked app message
  • Click Open Anyway

Sync is stuck

  • Check your internet connection
  • Close Minima and restart it
  • Make sure your Mac isn't sleeping - adjust Energy settings if needed

Need help?

  • Join the Minima Discord
  • Visit docs.minima.global
