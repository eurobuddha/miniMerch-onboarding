📱 Android Setup Guide

Get a Minima node running on your phone in seconds

← All Guides macOS Windows

Install Minima

Download the Minima app from the Google Play Store. Open it and allow the battery settings when prompted — your node starts automatically.

💡 No Play Store?

Download the latest APK directly from GitHub.

After Install

Tap to connect to the network when prompted. Your node will sync with the blockchain.

⚠️ Write Down Your Seed Phrase

Open the Security MiniDapp and back up your 24-word seed phrase immediately. It is the only way to recover your coins. Write it on paper and store it safely.

Get Your Keys for miniMerch

You'll need these for miniMerch setup:

  • Minima Address (starts with 0x): Open Wallet MiniDapp → Receive → Copy address
  • Maxima Public Key (starts with Mx): Open Terminal MiniDapp → type maxima → copy mxpublickey

Troubleshooting & Battery Settings

Minima keeps losing sync

Some manufacturers aggressively kill background apps. Adjust battery settings for Minima:

  • Samsung: Settings → Battery → Background usage limits → Never sleeping apps → Add Minima
  • Huawei / Redmi / ZTE: Disable "Manage Automatically" for Minima in battery settings
  • OPPO / Realme: Keep fewer than 5 apps allowed to run in the background
  • Other: Visit dontkillmyapp.com

Advanced: Desktop Connect & Custom Password

Desktop Connect

Access your phone node from a computer on the same WiFi: open the Minima app → Settings → Desktop Connect. Visit the URL shown on your computer and enter the displayed password.

Custom Password

Tap the top of the screen to show the MinimaOS title bar → 3 dots → Startup Params → enter -mdspassword yOurp@ssw0rdhere → Save → Shutdown to restart.

Password must be 12+ characters: a-z A-Z 0-9 !@#=?+<>,.-_'()/
