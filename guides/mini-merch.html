🛒 miniMerch Setup Guide

Install and configure your miniMerch shop

← All Guides ← Back Home

Prerequisites

Before setting up miniMerch, make sure you have:

  • Minima installed - Follow the node setup guide for your platform
  • Node synced - Your Minima node should be fully synced
  • Your public key - You'll need this to receive encrypted orders
  • Optional: CoinMarketCap API key for Minima pricing
💡 Quick Check

Not sure if you have Minima? Go to the homepage - it will detect your node automatically.

Step 1: Install the CLI Tool

miniMerch uses a command-line tool to generate and manage your shops. Install it with npm:

Option A: Using npx (Recommended)

Run without installing:

npx mini-merch-installer

Option B: Global Install

Install globally on your system:

npm install -g mini-merch

Verify Installation

mini-merch --version

You should see the version number if installed correctly.

🔧 Need Node.js?

If you don't have Node.js installed, download it from nodejs.org. The installer includes npm.

Step 2: Get Your Public Key

Your public key is used to encrypt orders so only you can read delivery addresses.

On Mobile

  1. Open the Minima app
  2. Tap Maxima at the bottom
  3. Your public key is displayed at the top
  4. Tap it to copy

On Desktop

  1. Open Minima Desktop
  2. Click Maxima in the sidebar
  3. Your public key is displayed
  4. Click to copy

Via Terminal (Linux/Mac/Windows)

maxima

This shows your full contact address including public key.

Your public key starts with Mx.

Step 3: Get a CoinMarketCap API Key (Optional)

For real-time Minima pricing, get a free API key from CoinMarketCap:

  1. Visit coinmarketcap.com/api
  2. Create a free account (or sign in)
  3. Go to Dashboard → API Keys
  4. Click Create Key
  5. Copy your API key
💡 Why is this optional?

If you don't provide an API key, miniMerch will use the free CoinGecko API for pricing, or a default fallback price.

Step 4: Run the Setup Wizard

The setup wizard guides you through configuration:

mini-merch setup

You'll be prompted for:

  1. Minima address - Your Minima wallet address (starts with 0x)
  2. CoinMarketCap API key - Press Enter to skip
  3. Vendor public key - Your Maxima public key (starts with Mx)

Your configuration is saved locally. You can change it anytime with:

mini-merch config

Step 5: Generate Your Shop

Create a new miniMerch shop:

mini-merch generate

You'll be asked:

  1. Product name - What are you selling?
  2. Pricing mode:
    • weight - Price per gram (for products like herbs)
    • units - Fixed price per item
  3. Price - Your base price in USD
  4. Product image - URL to product image (optional)
  5. Shipping options:
    • UK Domestic
    • International
    • Digital Delivery

The wizard generates two files:

  • shop.mds.zip - Your customer-facing shop (MiniDapp)
  • inbox.mds.zip - Your order management MiniDapp

Step 6: Install Your MiniDapps

Install the generated MiniDapps to your Minima node:

Using the CLI (Recommended)

mini-merch install

This installs both shop and inbox MiniDapps to your local node.

Manual Installation

  1. Open Minima MiniDapp Hub: https://127.0.0.1:9003
  2. Click Upload MiniDapp
  3. Select shop.mds.zip
  4. Repeat for inbox.mds.zip

Step 7: Test Your Shop

Verify everything is working:

  1. Open the MiniDapp Hub
  2. Find miniShop in your MiniDapps list
  3. Click to open your shop
  4. Select a product and try the checkout flow
  5. Open miniMerch Inbox to see the test order
🎉 Congratulations!

If you can see test orders in your inbox, your shop is working!

Sharing Your Shop

To let customers access your shop:

Local Network

  1. Make sure Minima is running
  2. Find your local IP address (e.g., 192.168.1.100)
  3. Share: https://192.168.1.100:9003/minidapp?mds=shop

Public Access

For a public shop accessible anywhere:

  1. Set up Minima with remote access enabled
  2. Configure your router to forward port 9003
  3. Use a dynamic DNS service if you have a dynamic IP
  4. Or host the generated files on any static web host
🌐 The Shop Files

The shop.mds.zip contains everything needed to run your shop. You can host it on IPFS, a web server, or distribute it directly.

Managing Orders

Use the miniMerch Inbox MiniDapp to manage orders:

  • View Orders - See incoming orders with encrypted delivery addresses
  • Reply to Buyers - Send encrypted messages about their order
  • Order History - Track past orders and responses

Fulfillment Flow

  1. New order arrives in inbox
  2. View the encrypted delivery address
  3. Pack and ship the product
  4. Reply to buyer if needed
  5. Mark order as fulfilled

CLI Commands Reference

# Setup and configuration
mini-merch setup           # Configure vendor details
mini-merch config          # View or change settings
mini-merch config --show   # Display current config

# Shop management
mini-merch generate        # Generate new shop MiniDapp
mini-merch install         # Install MiniDapps to node
mini-merch uninstall       # Remove MiniDapps from node

# Help
mini-merch --help          # Show all commands
mini-merch --version       # Show version

Troubleshooting

"Command not found" error

Make sure npm global bin directory is in your PATH. On macOS/Linux, add to your shell config:

export PATH="$PATH:$(npm bin -g)"

MiniDapp won't install

  • Make sure your Minima node is running
  • Check that MiniDapp System is enabled
  • Try installing manually via the MiniDapp Hub

Can't see MiniDapps

  • Refresh the MiniDapp Hub
  • Make sure MiniDapps installed successfully
  • Check Minima logs for errors
