🛒 miniMerch Setup Guide

Set up your miniMerch shop in minutes

← All Guides ← Back Home

Prerequisites

Before setting up miniMerch, make sure you have:

  • Minima installed - Follow the node setup guide for your platform
  • Node synced - Your Minima node should be fully synced
  • CoinMarketCap API key (optional) - For real-time Minima pricing

Step 1: Install the CLI Tool

miniMerch uses a command-line tool to generate your shops. Install it with npm:

npm install -g @eurobuddha/mini-merch
💡 Need Node.js?

If you don't have Node.js installed, download it from nodejs.org. The installer includes npm.

Step 2: Get Your Keys

You'll need three pieces of information:

Minima Address

Your wallet address for receiving payments:

  1. Open the Minima app
  2. Go to Settings → My Addresses
  3. Copy your default address (starts with 0x)

Maxima mxpublickey

Your public key for encrypting orders. This must be obtained from the Terminal.

  1. Open the Terminal MiniDapp in Minima
  2. Type the following command:
maxima
  1. Press Enter
  2. Find the line that says "mxpublickey":
  3. Copy the value - it starts with Mx and is a long string

CoinMarketCap API Key (Optional)

For accurate Minima pricing in your shop:

  1. Visit coinmarketcap.com/api
  2. Create a free account
  3. Go to Dashboard → API Keys → Create Key
  4. Copy your API key

If you skip this, miniMerch will use a default price.

Step 3: Run Setup Command

Configure your vendor details with this command:

mini-merch setup <minima-address> <cmc-api-key> <mxpublickey>

Example:

mini-merch setup 0x465CA86A9B5756F45DEB667A69B3DBEC1B82B211 c1d37f5f89564ca58 MxG18HGG6FJ038614Y8CW46US6G20810K0070CD00Z83282G60G19TUFFWSB6EEF...

This saves your configuration locally. You only need to run this once.

Step 4: Generate Your Shop

Create your shop MiniDapp:

mini-merch generate -n "Product Name" -m weight -p 5 -w 500

Command Options

Flag Description Example
-n Product name -n "Organic Barley"
-m Mode: weight or units -m weight
-p Price per gram/unit (USD) -p 5
-w Total weight in grams (for weight mode) -w 500
-u Max units (for units mode) -u 50
-d Product description -d "Premium malt"
-i Product image path -i ./photo.jpg

Examples

Weight mode (selling by weight):

mini-merch generate -n "Organic Barley" -m weight -p 5 -w 1000 -d "Premium malting barley"

Units mode (selling fixed items):

mini-merch generate -n "PDF Bundle" -m units -p 25 -u 50 -d "Collection of guides"

Step 5: Your Generated Files

After running the generate command, your files are created in a dist/ folder:

🛒

miniMerch_YourProduct.mds.zip

Your shop. This is what customers will use to place orders. Share this file with buyers.

📥

miniMerchInbox.mds.zip

Your order inbox. Install this on YOUR node to receive and manage orders.

The shop file is named after your product. For example, if you used -n "Coffee", you'll get miniMerch_Coffee.mds.zip.

Step 6: Install Your Inbox on Your Node

You need to install the inbox MiniDapp on your Minima node to receive orders.

Accessing the MiniDapp Hub

Option A: Desktop Connect (from your phone)

For a better experience, you can access your phone's node from your desktop:

  1. Open the Minima app on your phone
  2. Go to Settings → Desktop Connect
  3. Copy the URL and password shown
  4. Open that URL in your computer's browser
  5. Enter the password to log in
  6. Navigate to the MiniDapp Hub

Option B: Local Access (node running on this PC)

If you're running Minima directly on your computer:

  1. Open your browser
  2. Go to: http://127.0.0.1:9003
  3. Navigate to the MiniDapp Hub

Installing the Inbox

  1. In the MiniDapp Hub, click the + (plus) button
  2. Navigate to your dist/ folder
  3. Select miniMerchInbox.mds.zip
  4. The inbox MiniDapp is now installed
💡 Note

You only need to install the inbox on your node. The shop file is what your customers use - you share that with buyers.

Managing Your MiniDapps

Updating a MiniDapp

  1. Right-click on the miniMerch Inbox
  2. Select "Update"
  3. Select the new .mds.zip file

Deleting a MiniDapp

  1. Right-click (or long-press on mobile) on the MiniDapp
  2. Select "Delete MiniDapp"
  3. Confirm the deletion

Sharing Your Shop

To let customers place orders:

  1. Find your shop file in the dist/ folder (named miniMerch_YourProduct.mds.zip)
  2. Share this file directly with customers
  3. Customers install it on their own Minima node to place orders

Alternatively, you can host the files on a web server or IPFS for easier access.

CLI Commands Reference

# One-time setup
mini-merch setup <address> <cmc-key> <mxpublickey>

# Generate shop
mini-merch generate -n "Name" -m weight -p 5 -w 500

# View config
mini-merch config --show

# Reset config
mini-merch config --reset

# Help
mini-merch --help

Troubleshooting

"Command not found" error

Make sure npm global bin directory is in your PATH. On macOS/Linux, add to your shell config:

export PATH="$PATH:$(npm bin -g)"

Can't access MiniDapp Hub

  • Make sure your Minima node is running
  • For local access: go to http://127.0.0.1:9003
  • For Desktop Connect: check Settings on your phone
