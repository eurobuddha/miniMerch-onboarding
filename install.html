🛒 Install miniMerch

First get a Minima node, then install miniMerch

Step 1: Get a Minima Node

miniMerch runs on the Minima blockchain. You need a Minima node first.

📱 Choose Your Platform

Install Minima on your device:

🤖 Android 🍎 macOS 🪟 Windows 🐧 Linux

Step 2: Install miniMerch

Choose how you want to run miniMerch:

🖥 Option A: miniMerch Studio (Recommended)

A desktop app for macOS and Windows. No terminal, no npm. Download, install, and build shops visually.

🖥 Download miniMerch Studio 📖 Installation guide

⌨️ Option B: CLI Tool (Developers)

For those who prefer the command line. Requires Node.js.

Run this command in your terminal:

npm install -g @eurobuddha/mini-merch
✅ Copied to clipboard!

Alternative: No Install Needed

If you don't want to install anything globally, use npx:

npx mini-merch setup
💡 Need Node.js?

If you see "command not found", install Node.js from nodejs.org. The installer includes npm.

Step 3: Configure Your Shop

After installing miniMerch, run these commands:

1. Run Setup Wizard

mini-merch setup

This will ask for your Minima address, public key, and optional CoinMarketCap API key.

2. Generate Your Shop

mini-merch generate

This creates your shop MiniDapp with your product details.

3. Install to Node

mini-merch install

This installs your shop and inbox to your Minima node.

Troubleshooting

Install Node.js from nodejs.org. This includes npm automatically.

Fix npm permissions:

mkdir ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

Then try installing again.

npm installations can take 1-2 minutes. If it's longer, try:

  • Check your internet connection
  • Try a different registry: npm install -g @eurobuddha/mini-merch --registry https://registry.npmjs.org
