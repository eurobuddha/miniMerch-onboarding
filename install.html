🛒 Install miniMerch

Choose the option that works for you

Option A: miniMerch Studio (Easiest)

A desktop app for macOS and Windows. No terminal, no npm. Download, install, and build shops visually.

🖥 Download miniMerch Studio 📖 Installation guide
🍎 macOS
  1. Download the .dmg
  2. Drag to Applications
  3. Right-click → Open (once)
  4. Browser opens at localhost:3456
🪟 Windows
  1. Download the Setup.exe
  2. SmartScreen → More info → Run anyway
  3. One-click install (no admin)
  4. Desktop shortcut → browser opens

Option B: CLI Tool (Advanced)

For developers who prefer the command line. Requires Node.js.

Quick Install

Run this command in your terminal:

npm install -g @eurobuddha/mini-merch
✅ Copied to clipboard!

Alternative: No Install Needed

If you don't want to install anything, use npx:

npx mini-merch setup

Platform Instructions

🪟

Windows

Open Command Prompt or PowerShell and paste the command above.

🍎

macOS / Linux

Open Terminal and paste the command above.

💡 Need Node.js?

If you see "command not found", install Node.js from nodejs.org. The installer includes npm.

Next Steps

After installation:

1. Run Setup Wizard

mini-merch setup

This will ask for your Minima address, public key, and optional CoinMarketCap API key.

2. Generate Your Shop

mini-merch generate

This creates your shop MiniDapp with your product details.

3. Install to Node

mini-merch install

This installs your shop and inbox to your Minima node.

Troubleshooting

Install Node.js from nodejs.org. This includes npm automatically.

Fix npm permissions:

mkdir ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

Then try installing again.

npm installations can take 1-2 minutes. If it's longer, try:

  • Check your internet connection
  • Try a different registry: npm install -g @eurobuddha/mini-merch --registry https://registry.npmjs.org
